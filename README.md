## 📖 Descripción del Repositorio
Este repositorio centraliza todos los talleres, prácticas y proyectos desarrollados a lo largo del curso de Desarrollo de Aplicaciones Móviles. Cada taller explora diferentes conceptos y componentes del framework **Flutter** utilizando el lenguaje **Dart**.

## 🌿 Estrategia de Ramas (Git Flow)
Para mantener un historial limpio y seguir las buenas prácticas de control de versiones, este repositorio utiliza la siguiente estructura de ramas:

* **`main`**: Rama estable de producción. Solo recibe integraciones (Pull Requests) funcionales y revisadas.
* **`dev`**: Rama de desarrollo e integración. Aquí se unen los talleres antes de pasar a la rama principal.
* **`feature/taller[X]`**: Ramas de características individuales. Cada taller nace desde `dev` (ej. `feature/taller1`, `feature/taller2`) y contiene el trabajo aislado de esa entrega específica.
